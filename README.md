# Knowledge transfer between simple discrete worlds: interactive companion

An interactive page for the paper *Knowledge transfer between simple discrete worlds* (Silvère Gangloff, Jan Hůla).

- Build a world from rules, solve a puzzle in it, and see which forbidden pattern you break.
- Guess the hidden rules from two solved examples, as the "examples" model must.
- Browse the four levels of novelty and the main results.

Everything runs in the browser: puzzles are generated and checked live by a small exact solver (`index.html`, no build step, no dependencies).

Paper: https://arxiv.org/abs/2610.15081 · Code and data: https://github.com/Sfgangloff/GridWorldHyperNetworks
